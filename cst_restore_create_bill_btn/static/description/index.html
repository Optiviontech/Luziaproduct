Classic Create Bill Button (Odoo 18 Style)
This module brings back the classic Create Bill button directly into the Purchase Order form view, following the familiar Odoo 18 workflow, so users can generate vendor bills instantly while reviewing a purchase order.

Detailed Features List

Restore Create Bill in Form View

  • In Odoo 19, the Create Bill action is no longer available directly in the Purchase Order form view. This module restores that button in the form header, enabling users to create vendor bills instantly while reviewing purchase order details−just like in Odoo 18.

Faster & More User-Friendly Billing

  • By bringing back the Create Bill button to the form view, this module reduces extra clicks and context switching, improving efficiency for accounting and purchase teams while preserving Odoo 19's modern billing options.
